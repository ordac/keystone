# Keystone

A lightweight, session-locked player data library for Roblox.

## Features

- Session locking
- Autosaving
- Save queue
- BindToClose support
- Save retries
- Deep reconciliation
- Client snapshots
- Change signals

[dependencies]
Keystone = "ordac/keystone@0.1.2"
